# Flickr Pro Popup Remover

[English version](README.md)

Небольшой юзерскрипт, который убирает полноэкранное окно **«Upgrade to Pro»**, постоянно всплывающее на Flickr при просмотре фотографий, вместе с затемнением, а также баннер **«Upgrade to Flickr Pro to hide these ads»** и сами **рекламные блоки**. Всё это — **без морганий**.

> Проект не связан с Flickr и не одобрен им. Скрипт лишь прячет элементы страницы (рекламные и призывающие купить Pro блоки) в вашем браузере: он не открывает серверные функции Pro, такие как безлимитные загрузки или подробная статистика. Учтите, что отсутствие рекламы — тоже одно из платных преимуществ Flickr Pro, так что пользуйтесь скриптом на своё усмотрение.

## Что удаляется

### 1. Окно «Upgrade to Pro»

Это окно (и затемнение за ним) скрипт прячет:

![Пример окна Flickr «Upgrade to Pro», которое удаляется](images/popup-example.png)

_Скриншот рекламного окна Flickr приведён только для иллюстрации. Flickr и фотография в окне принадлежат их владельцам._

### 2. Баннер «Upgrade to Flickr Pro to hide these ads»

Этот рекламный текст под верхним меню удаляется:

![Пример баннера «Upgrade to Flickr Pro to hide these ads», который удаляется](images/banner-example.png)

Удаляемый текст: **Upgrade to Flickr Pro to hide these ads** (блок `.upgrade-to-pro-cta`).

### 3. Рекламные блоки

Рекламные слоты на страницах фото прячутся вместе с обёрткой, поэтому пустого места не остаётся:

```html
<div class="photo-page-i-m-container">
  <div class="moola-wrapper"> <div data-aaad="true" ...> рекламный слот </div> </div>
  <p class="upgrade-to-pro-cta">Upgrade to Flickr Pro to hide these ads</p>
  <div class="navad-timer-container">...</div>
</div>
```

Скрываемые контейнеры: `.photo-page-i-m-container`, `.moola-wrapper`, `[data-aaad]`, `.navad-timer-container`.

На страницах `https://www.flickr.com/photos/…` дополнительно скрывается пустая рекламная полоса над шапкой (`.nav-ad-container`), чтобы она не занимала место.

## Возможности

- Прячет рекламное окно Pro и затемнение до отрисовки браузером (окно не успевает мигнуть).
- Прячет баннер «Upgrade to Flickr Pro to hide these ads» (`.upgrade-to-pro-cta`).
- Прячет рекламные блоки (`.photo-page-i-m-container`, `.moola-wrapper`, `[data-aaad]`) без пустого места.
- Возвращает прокрутку страницы, которую окно блокирует.
- Не трогает остальные окна Flickr (поделиться, редактирование и т.д.).
- Без зависимостей, без сетевых запросов, без сбора данных. Около 100 строк читаемого кода.

## Установка

1. Установите менеджер юзерскриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Firefox, Chrome, Edge, Safari)
   - [Violentmonkey](https://violentmonkey.github.io/)
   - [Greasemonkey](https://www.greasespot.net/) (Firefox)
2. Установите скрипт:
   - **[Установить с GitHub](https://github.com/aspidovss/flickr-pro-popup-remover/raw/main/flickr-pro-popup-remover.user.js)**
   - или с **[Greasy Fork](https://greasyfork.org/en/scripts/599316-flickr-pro-popup-remover)** (рекомендуется: автообновления)
3. Откройте любую страницу фото на Flickr. Окно больше не появляется.

## Требования

Браузер с поддержкой CSS `:has()`: Firefox 121+, Chrome/Edge 105+, Safari 15.4+.

## Как это работает

Flickr отрисовывает окно как элемент `fluid-modal-view` (внутри — `upsell-modal-view`) рядом с затемнением `fluid-modal-overlay`. Скрипт:

1. добавляет CSS на `document-start`: прячет любое окно с рекламной разметкой и держит все затемнения невидимыми, пока не подтверждено, что они относятся к обычному окну;
2. следит за DOM через `MutationObserver` (синхронно, до отрисовки кадра) и показывает затемнение обычных окон;
3. один раз нажимает крестик в рекламном окне, чтобы Flickr сам привёл своё состояние в порядок;
4. прячет баннер `.upgrade-to-pro-cta` и рекламные контейнеры (`.photo-page-i-m-container`, `.moola-wrapper`, `[data-aaad]`) обычными CSS-правилами.

Скрипт только **прячет** элементы. Запросы к рекламным серверам он не блокирует; для этого нужен блокировщик контента.

Id элементов у Flickr генерируются динамически (`yui_3_18_1_…`), поэтому скрипт ориентируется на устойчивые имена классов и шаблоны ссылок.

## Настройка

Откройте скрипт в менеджере юзерскриптов и поставьте `DEBUG = true` — действия скрипта будут выводиться в консоль браузера (отфильтруйте её по `FPR`).

## Если что-то не работает

- **Окно всё равно появляется.** Убедитесь, что включён только один скрипт для окон Flickr и что браузер подходит по требованиям. Возможно, Flickr изменил разметку — создайте issue.
- **Как сообщить о проблеме.** Поставьте `DEBUG = true`, обновите страницу и приложите строки `[FPR]` из консоли и скриншот Инспектора с HTML окна (правый клик по окну → «Исследовать»).
