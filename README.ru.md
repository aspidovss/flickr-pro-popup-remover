# Flickr Pro Popup Remover

[English version](README.md)

Небольшой юзерскрипт, который убирает полноэкранное окно **«Upgrade to Pro»**, постоянно всплывающее на Flickr при просмотре фотографий, вместе с затемнением — **без морганий**.

> Проект не связан с Flickr и не одобрен им. Скрипт лишь прячет рекламу в вашем браузере: он не обходит платный доступ и не открывает функции Pro.

## Что удаляется

Вот это окно (и затемнение за ним) скрипт прячет:

![Пример окна Flickr «Upgrade to Pro», которое удаляется](images/popup-example.png)

_Скриншот рекламного окна Flickr приведён только для иллюстрации. Flickr и фотография в окне принадлежат их владельцам._

## Возможности

- Прячет рекламное окно Pro и затемнение до отрисовки браузером (окно не успевает мигнуть).
- Возвращает прокрутку страницы, которую окно блокирует.
- Не трогает остальные окна Flickr (поделиться, редактирование и т.д.).
- Без зависимостей, без сетевых запросов, без сбора данных. Около 100 строк читаемого кода.

## Установка

1. Установите менеджер юзерскриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Firefox, Chrome, Edge, Safari)
   - [Violentmonkey](https://violentmonkey.github.io/)
   - [Greasemonkey](https://www.greasespot.net/) (Firefox)
2. Установите скрипт:
   - **[Установить с GitHub](https://github.com/aspidovss/flickr-pro-popup-remover/raw/main/flickr-pro-popup-remover.user.js)**
   - **[Установить с Greasy Fork](https://greasyfork.org/en/scripts/599316-flickr-pro-popup-remover)**
3. Откройте любую страницу фото на Flickr. Окно больше не появляется.

## Требования

Браузер с поддержкой CSS `:has()`: Firefox 121+, Chrome/Edge 105+, Safari 15.4+.

## Как это работает

Flickr отрисовывает окно как элемент `fluid-modal-view` (внутри — `upsell-modal-view`) рядом с затемнением `fluid-modal-overlay`. Скрипт:

1. добавляет CSS на `document-start`: прячет любое окно с рекламной разметкой и держит все затемнения невидимыми, пока не подтверждено, что они относятся к обычному окну;
2. следит за DOM через `MutationObserver` (синхронно, до отрисовки кадра) и показывает затемнение обычных окон;
3. один раз нажимает крестик в рекламном окне, чтобы Flickr сам привёл своё состояние в порядок.

Id элементов у Flickr генерируются динамически (`yui_3_18_1_…`), поэтому скрипт ориентируется на устойчивые имена классов и шаблоны ссылок.

## Настройка

Откройте скрипт в менеджере юзерскриптов и поставьте `DEBUG = true` — действия скрипта будут выводиться в консоль браузера (отфильтруйте её по `FPR`).

## Если что-то не работает

- **Окно всё равно появляется.** Убедитесь, что включён только один скрипт для окон Flickr и что браузер подходит по требованиям. Возможно, Flickr изменил разметку — создайте issue.
- **Как сообщить о проблеме.** Поставьте `DEBUG = true`, обновите страницу и приложите строки `[FPR]` из консоли и скриншот Инспектора с HTML окна (правый клик по окну → «Исследовать»).
